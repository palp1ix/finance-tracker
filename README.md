# Траты — заметки о покупках с ИИ-аналитикой

Local-first PWA для учёта трат. Пишешь покупки в свободной форме («шаурма 14р», «VPN 4.99€», «вчера кино 32»), жмёшь **Обработать ✨** — ИИ (OpenRouter) разбирает записи в структуру, и они попадают в статистику. Данные хранятся **только на устройстве** (IndexedDB).

Дизайн перенесён 1:1 из `prototype.html` (токены светлой/тёмной темы, сетка 4/8, скругления, анимации, нижняя панель с композером + счётчик + кнопка + навигация).

## Стек

- Vite + React + TypeScript + Tailwind CSS v4
- `vite-plugin-pwa` (manifest, service worker, офлайн)
- Dexie (IndexedDB) + `dexie-react-hooks`
- OpenRouter напрямую с клиента, валидация ответа через Zod
- Vitest (юнит) + Playwright (e2e)

## Запуск локально

```bash
pnpm install
pnpm dev          # http://localhost:5173
pnpm build        # сборка в dist/
pnpm preview      # превью сборки
pnpm test         # юнит-тесты
pnpm e2e          # e2e (сначала ставит chromium: pnpm exec playwright install chromium)
pnpm typecheck
```

## Деплой

### GitHub Pages (рекомендуется)

1. Запушь репозиторий на GitHub.
2. В репозитории: **Settings → Pages → Source = GitHub Actions**.
3. Включённый воркфлоу `.github/workflows/deploy.yml` сам соберёт и задеплоит `dist/` на каждый push в `main`.
4. Приложение будет доступно на `https://<user>.github.io/<repo>/`.

Сборка использует `base: './'` — относительные пути, поэтому работает и из подпапки `/repo/`, и с корня.

### Vercel / Cloudflare Pages

- Build command: `pnpm build`
- Output directory: `dist`
- Никаких переменных окружения не нужно.

## Установка на iPhone (без Apple Developer)

Открой сайт в Safari → **Поделиться** → **На экран «Домой»**. Приложение откроется во весь экран (`display: standalone`), с иконкой и офлайн-режимом.

> Safari чистит данные обычного сайта после ~7 дней неактивности; у установленного на «Домой» приложения такого нет. Держи свежий бэкап: **Настройки → Экспорт JSON**.

## Настройка ИИ

1. Получи ключ на [openrouter.ai/keys](https://openrouter.ai/keys).
2. Вставь его в **Настройки → ИИ (OpenRouter)**.
3. Ключ хранится только на устройстве и отправляется напрямую в OpenRouter.

Без ключа приложение полностью работает как обычный трекер (заметки + ручное редактирование + статистика), просто кнопка «Обработать ✨» попросит ключ.

## Мультитеминг

- **Режим**: Системная / Светлая / Тёмная (по `prefers-color-scheme` + ручное переключение).
- **Акцентные темы**: Фиолетовый, Синий, Изумрудный, Розовый, Янтарный, Бирюзовый — меняют цвет акцента, градиенты и «мягкие» фоны по всему интерфейсу.
- Выбор сохраняется в настройках и применяется без мигания (тема ставится до первой отрисовки).

## Структура

```
src/
  domain/       типы, категории, валюты, даты (чистые функции, покрыты тестами)
  db/           Dexie-схема и CRUD
  ai/           OpenRouter-клиент, zod-схема, промпт и обработка пачкой, инсайт
  theme/        темы и акценты
  state/        SettingsProvider (загрузка/сохранение + применение темы)
  features/     notes / stats / settings (вьюхи)
  components/   Toast, Bottom sheet
  lib/          импорт/экспорт JSON/CSV
```

## Данные

- `Entry`: `id`, `rawText`, `createdAt`, `updatedAt`, `status` (`pending` | `processed` | `error`), `error?`, `parsed?` (`title`, `amount`, `currency`, `categoryId`, `occurredAt`, `type`, `note`).
- `Settings`: ключ, модель, валюта по умолчанию, курсы к BYN, список категорий (можно добавлять свои), тема и акцент.
